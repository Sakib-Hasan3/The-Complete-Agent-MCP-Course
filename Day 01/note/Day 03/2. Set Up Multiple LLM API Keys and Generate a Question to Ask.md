# Set Up Multiple LLM API Keys and Generate a Question to Ask

এই Topic-টি মূলত n8n দিয়ে AI Agent তৈরি করার সময় একাধিক AI Model-এর API Key সেটআপ করা এবং সেগুলো ব্যবহার করে AI-কে প্রশ্ন করার বিষয় নিয়ে।

চলো একদম Basic থেকে বুঝি।

## 1. LLM API Key কী?

প্রথমে তিনটি বিষয় বুঝতে হবে:

- LLM: Large Language Model। যেমন GPT, Gemini, Claude, Llama।
- API: একটি Software-এর সঙ্গে অন্য Software-এর যোগাযোগের মাধ্যম।
- API Key: একটি Secret Credential, যা দিয়ে কোনো Service তোমার API Request শনাক্ত ও অনুমোদন করে।

ধরো, তুমি Python দিয়ে Gemini ব্যবহার করতে চাও। তখন Google তোমাকে একটি API Key দেবে।

এই Key ব্যবহার করে তোমার Application Gemini Model-এর কাছে Request পাঠাতে পারবে।

সহজভাবে:

তোমার Application → API Key → AI Provider → LLM → Response

## 7. API Key ব্যবহার করার সময় Security

কিছু গুরুত্বপূর্ণ বিষয়:

- API Key কখনো অন্য কাউকে দেবে না।
- GitHub-এ API Key Push করবে না।
- n8n Credentials ব্যবহার করবে।
- API Usage এবং Billing Monitor করবে।
- অপ্রয়োজনীয় Permission দেবে না।
- Key Leak হলে Provider Dashboard থেকে Revoke করে নতুন Key তৈরি করবে।
