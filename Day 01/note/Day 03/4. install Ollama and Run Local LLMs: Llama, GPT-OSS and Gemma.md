# Install Ollama and Run Local LLMs: Llama, GPT-OSS and Gemma

এই lesson-এ আমরা শিখব কীভাবে নিজের computer-এ Ollama install করে Internet-based API ছাড়াই Local LLM চালানো যায়।

তিনটি model family নিয়ে কাজ করব:

1. Llama — Meta-এর open-weight language models
2. GPT-OSS — OpenAI-এর open-weight models
3. Gemma — Google-এর open models

তোমার Manjaro laptop-এর configuration (Intel i5-1135G7, 8 GB RAM) বিবেচনায় আমরা ছোট model দিয়ে শুরু করব। বড় model চালাতে গেলে RAM-এর সীমাবদ্ধতা দেখা দিতে পারে।

## ২. Manjaro Linux-এ Ollama install

তুমি Manjaro ব্যবহার করো, তাই নিচের Linux installation পদ্ধতি অনুসরণ করো। Ollama-এর official Linux installer ব্যবহার করব।&#x20;

[image](https://www.google.com/s2/favicons?domain=https://github.com\&sz=32)

GitHub+1



Step 1 — Terminal খুলে install command চালাও

```
curl -fsSL https://ollama.com/install.sh | sh
```

এখানে:

- `curl` — Internet থেকে installer download করে।
- `-f` — HTTP error হলে fail করে।
- `-sS` — অপ্রয়োজনীয় output কমায়, error দেখায়।
- `-L` — redirect follow করে।
- `| sh` — download করা script shell দিয়ে চালায়।

Step 2 — Installation verify করো

```
ollama --version
```

Version দেখালে installation হয়েছে।

Step 3 — Ollama service check করো

```
systemctl status ollama
```

যদি service inactive থাকে, চালাও:

```
sudo systemctl enable --now ollama
```

তারপর আবার:

```
systemctl status ollama
```



Expected

`active (running)` দেখাবে।

## ৪. Download করা model-গুলো কীভাবে manage করবে?

সব model-এর list:

```
ollama list
```

কোন model বর্তমানে memory-তে চলছে:

```
ollama ps
```

Model বন্ধ করতে:

```
ollama stop llama3.2:1b
```

Model delete করতে:

```
ollama rm llama3.2:1b
```

এগুলো খুব গুরুত্বপূর্ণ—কারণ laptop-এর storage ও RAM সীমিত।

## ৫. Ollama-এর Local API কীভাবে কাজ করে?

এবার একটু AI Engineering শেখা যাক।

Ollama শুধু terminal-এ chat করার জন্য নয়। Python, n8n বা নিজের তৈরি application থেকেও model call করা যায়।

Ollama সাধারণত local API চালায়:

`http://localhost:11434`

একটি terminal-এ নিচের command চালিয়ে পরীক্ষা করো:

```
curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2:1b",
  "messages": [
    {
      "role": "user",
      "content": "Explain AI Agent in simple Bangla"
    }
  ],
  "stream": false
}'
```

এখানে:

- `localhost` = তোমার নিজের computer।
- `11434` = Ollama-এর default API port।
- `/api/chat` = chat request endpoint।
- `model` = কোন model ব্যবহার করবে।
- `messages` = তোমার conversation।
- `stream: false` = সম্পূর্ণ উত্তর একসঙ্গে ফেরত দেবে।

Ollama-এর API documentation: [Chat API](https://docs.ollama.com/api/chat?utm_source=chatgpt.com)।&#x20;

## ৭. আজকের শেখার বিষয়গুলো

| Term          | অর্থ                                                                |
| ------------- | ------------------------------------------------------------------- |
| Ollama        | Local LLM runtime                                                   |
