# Agentic AI Design Patterns: Chaining, Routing, Orchestration

এই Topic-টি বুঝতে হলে আগে একটি কথা মনে রাখো: AI Agent Design Pattern হলো AI-কে দিয়ে জটিল কাজ করানোর জন্য কাজগুলো সাজানোর একটি পদ্ধতি।

তুমি যখন AI Engineer হিসেবে বড় কোনো AI System তৈরি করবে, তখন একটি LLM-কে সব কাজ একসঙ্গে করতে না দিয়ে কাজগুলোকে ছোট ছোট ধাপে ভাগ করতে পারবে। কোন ধাপ আগে হবে, কোন AI কাজ করবে এবং একাধিক AI কীভাবে একসঙ্গে কাজ করবে—এসবই Design Pattern-এর অংশ।

আজ আমরা ৩টি গুরুত্বপূর্ণ Pattern শিখব:

1. Chaining
2. Routing
3. Orchestration

## 1. Chaining — একটির পর একটি কাজ

Chaining মানে হলো একটি কাজের Output-কে পরবর্তী কাজের Input হিসেবে ব্যবহার করা।

ধরো, তুমি একটি AI System তৈরি করছ, যা Research Paper-এর Summary তৈরি করবে।

Step 1: Research Paper

Input document

Step 2: Extract Information

প্রয়োজনীয় তথ্য বের করা

Step 3: Generate Summary

তথ্য থেকে Summary তৈরি

Step 4: Translate to Bangla

Summary বাংলায় অনুবাদ

এখানে:

- Step 2-এর Output → Step 3-এর Input
- Step 3-এর Output → Step 4-এর Input

এভাবেই Chain তৈরি হয়েছে।

### বাস্তব উদাহরণ

ধরো, তোমার কাছে একটি ইংরেজি Research Paper আছে। তুমি চাও সেটি বাংলায় বুঝতে।

AI System প্রথমে Paper-এর গুরুত্বপূর্ণ তথ্য বের করবে, এরপর Summary তৈরি করবে, তারপর বাংলায় অনুবাদ করবে।

প্রতিটি ধাপের কাজ নির্দিষ্ট।

কখন Chaining ব্যবহার করবে?

- Text summarization
- Document processing
- Translation pipeline
- Report generation
- AI content generation

মনে রাখার কৌশল

Chaining = Step 1 → Step 2 → Step 3

অর্থাৎ, একটি কাজ শেষ হলে তার ফলাফল দিয়ে পরবর্তী কাজ শুরু হবে।

## 2. Routing — সঠিক কাজের জন্য সঠিক পথ নির্বাচন

Routing হলো Input-এর ধরন বা পরিস্থিতি অনুযায়ী উপযুক্ত Processing Path নির্বাচন করা।

ধরো, তুমি একটি Customer Support AI তৈরি করেছ। Customer বিভিন্ন ধরনের প্রশ্ন করতে পারে:

- Payment সম্পর্কে
- Technical Problem সম্পর্কে
- Order Delivery সম্পর্কে

প্রতিটি প্রশ্নের জন্য একই Processing System ব্যবহার না করে উপযুক্ত পথ বেছে নেওয়া যায়।

Customer Message

"আমার Payment হচ্ছে না"

Router / Classifier

প্রশ্নের Category নির্ধারণ করে

Payment Support

Technical Support

Order Support

উপরের উদাহরণে Router বুঝতে চেষ্টা করবে প্রশ্নটি কোন Category-তে পড়ে। Payment-এর প্রশ্ন হলে Payment Support Path-এ পাঠাবে।

Routing সবসময় LLM দিয়ে করতে হবে এমন নয়। সাধারণ নিয়ম দিয়েও করা যায়। যেমন, IF Node দিয়ে কোনো নির্দিষ্ট শব্দ বা Field পরীক্ষা করা।

### বাস্তব উদাহরণ

তোমার Bangla Handwritten VLM Research Project-এ Routing ব্যবহার করা যেতে পারে:

- বাংলা Handwriting Image → Handwriting Recognition Model
- Printed Text Image → OCR Model
- Image অস্পষ্ট হলে → Image Enhancement Pipeline

এখানে Input অনুযায়ী ভিন্ন Processing Path বেছে নেওয়া হচ্ছে।

কখন Routing ব্যবহার করবে?

- Customer Support
- Multi-model AI Systems
- Different document types
- Image classification pipelines
- User intent detection

মনে রাখার কৌশল

Routing = Input → Decision → সঠিক Path

অর্থাৎ, কাজের ধরন বুঝে সঠিক জায়গায় পাঠানো।

## 3. Orchestration — একাধিক কাজ বা Agent-কে সমন্বয় করা

Orchestration হলো একাধিক কাজ, Tool বা AI Agent-কে সমন্বয় করে একটি বড় লক্ষ্য পূরণ করা।

এবার একটি বড় উদাহরণ দেখি।

ধরো, তুমি একটি AI Research Assistant তৈরি করতে চাও। এর কাজ হবে কোনো Topic নিয়ে Research করা এবং একটি Report তৈরি করা।

এখানে কয়েকটি আলাদা Agent থাকতে পারে:

- Research Agent → Research Paper খুঁজবে।
- Analysis Agent → Paper-এর ফলাফল বিশ্লেষণ করবে।
- Writing Agent → Report তৈরি করবে।
- Review Agent → Report-এর ভুল বা দুর্বলতা পরীক্ষা করবে।

এই Agent-গুলো কীভাবে কাজ করবে, কখন কোন Agent চালু হবে এবং একটির ফলাফল অন্যটির কাছে কীভাবে যাবে—এসব সমন্বয় করাই Orchestration।

Goal: Research Report তৈরি

Orchestrator

কাজ ভাগ করে এবং Agent-দের সমন্বয় করে

Research Agent

Paper সংগ্রহ

Analysis Agent

ফলাফল বিশ্লেষণ

Writing Agent

Report লেখা

Review Agent

Quality Check

Final Research Report

মনে রাখবে, Orchestration-এর অর্থ এই নয় যে অবশ্যই অনেকগুলো AI Agent লাগবে। একজন Orchestrator একাধিক Tools বা Workflow Step-ও পরিচালনা করতে পারে।

একইভাবে, সব Agent একসঙ্গে কাজ করবে এমনও নয়। কিছু কাজ Parallel-এ চলতে পারে, আবার কিছু কাজ আগের ধাপ শেষ হওয়ার পর শুরু হবে।

কখন Orchestration ব্যবহার করবে?

- Multi-agent research systems
- Complex customer support
- Software development agents
- Business process automation
- Multi-step data analysis

## 4. তিনটি Pattern-এর মধ্যে পার্থক্য

| Pattern       | মূল প্রশ্ন                              | সহজ উদাহরণ                             |
| ------------- | --------------------------------------- | -------------------------------------- |
| Chaining      | কোন কাজের পর কোন কাজ হবে?               | Extract → Summarize → Translate        |
| Routing       | কোন Input কোন পথে যাবে?                 | Payment question → Payment Support     |
| Orchestration | একাধিক কাজ বা Agent কীভাবে সমন্বিত হবে? | Research + Analysis + Writing + Review |

আরও সহজভাবে:

- Chaining = কাজগুলোকে ক্রমানুসারে সাজানো।
- Routing = সঠিক কাজের জন্য সঠিক পথ নির্বাচন।
- Orchestration = একাধিক কাজ বা Agent-কে সমন্বয় করা।
