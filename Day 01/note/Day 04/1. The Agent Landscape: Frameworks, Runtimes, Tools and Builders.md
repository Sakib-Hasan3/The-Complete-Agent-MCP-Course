# The Agent Landscape: Frameworks, Runtimes, Tools and Builders

আজকের lesson-এ আমরা Agentic AI ecosystem-এর একটি গুরুত্বপূর্ণ বিষয় শিখব।

এখন পর্যন্ত তুমি শিখেছ:

- LLM কী এবং OpenAI, Claude, Gemini, Groq কীভাবে কাজ করে।
- Ollama দিয়ে Local LLM চালানো।
- n8n দিয়ে AI Agent workflow তৈরি।
- একাধিক LLM call করা।
- LLM-as-a-Judge দিয়ে model ranking করা।

এবার বুঝব—AI Agent তৈরি করার জন্য কী কী technology লাগে এবং কোন technology কী কাজ করে।

## ১. Agent Landscape কী?

Agent Landscape বলতে AI Agent তৈরি, পরিচালনা, পরীক্ষা ও deploy করার জন্য ব্যবহৃত বিভিন্ন framework, runtime, tools এবং builders-এর ecosystem-কে বোঝায়।

একটি AI Agent তৈরি করতে শুধু LLM হলেই হয় না। আরও কিছু component প্রয়োজন।

ধরো, তুমি একটি AI Research Assistant তৈরি করবে। সে:

1. User-এর প্রশ্ন বুঝবে।
2. Internet থেকে research করবে।
3. প্রয়োজনীয় document পড়বে।
4. তথ্য বিশ্লেষণ করবে।
5. Report তৈরি করবে।

এই কাজগুলো করার জন্য বিভিন্ন technology একসঙ্গে ব্যবহার করতে হবে।

## ২. Agent Architecture-এর চারটি প্রধান অংশ

1\. LLM

Agent-এর reasoning ও language generation

GPT · Claude · Gemini · Llama

2\. Framework

Agent-এর logic ও workflow তৈরি

LangChain · LangGraph · CrewAI · AutoGen

3\. Runtime

Agent execute, manage ও control

Application server · Agent execution environment

4\. Tools & Integrations

Agent-কে বাইরের কাজ করার ক্ষমতা দেয়

Web Search · Database · API · Gmail · MCP

আর এগুলো ব্যবহার করে code ছাড়াই বা কম code-এ Agent বানানোর জন্য আছে Builders, যেমন n8n।

একটি বিষয় মনে রাখবে: এই চারটি অংশের সীমানা সবসময় আলাদা নয়। কোনো platform একাধিক কাজ করতে পারে।

## ৩. Agent Frameworks কী?

## ৪. Agent Runtimes কী?

Framework দিয়ে Agent-এর logic তৈরি করা যায়। কিন্তু Agent-কে বাস্তবে execute ও পরিচালনা করার জন্য একটি environment দরকার। এটিকে সাধারণভাবে Runtime বলা হয়।

উদাহরণ:

ধরো, তুমি একটি Agent বানালে। সে:

- User-এর message গ্রহণ করবে।
- LLM call করবে।
- Tool ব্যবহার করবে।
- Memory update করবে।
- প্রয়োজনে আবার LLM call করবে।

এই পুরো execution process পরিচালনার জন্য runtime বা execution environment প্রয়োজন।

### Runtime-এর দায়িত্ব

1. Agent execution শুরু করা।
2. Tool call পরিচালনা করা।
3. Agent-এর state ও conversation manage করা।
4. Timeout ও error handle করা।
5. প্রয়োজন হলে checkpoint ও resume করা।
6. Security এবং resource limits প্রয়োগ করা।

### Runtime ও Framework-এর পার্থক্য

| Framework                                      | Runtime                                                 |
| ---------------------------------------------- | ------------------------------------------------------- |
| Agent কীভাবে কাজ করবে তা তৈরি করতে সাহায্য করে | Agent-কে execute ও manage করে                           |
| Logic, tools, state design                     | Execution, lifecycle, resource management               |
| LangChain, LangGraph, CrewAI                   | Application server, managed agent execution environment |

বাস্তব উদাহরণ: LangGraph দিয়ে Agent workflow তৈরি করলে সেটি Python application হিসেবে চালাতে পারো। সেই application একটি server-এ deploy করলে server ও তার execution environment Agent-কে runtime support দেয়।

সব framework-এর নিজস্ব আলাদা runtime থাকতে হবে এমন নয়।

## ৫. Agent Tools কী?

Agent নিজে থেকে সব কাজ করতে পারে না। বাইরের service বা software-এর সাহায্য নিতে হয়।

এই বাইরের capability-গুলোকে Agent Tools বলা হয়।

যেমন:

| Tool        | Agent কী করতে পারবে?              |
| ----------- | --------------------------------- |
| Web Search  | Internet-এ তথ্য খুঁজবে            |
| Calculator  | হিসাব করবে                        |
| Database    | তথ্য সংরক্ষণ ও retrieve করবে      |
| Gmail API   | Email পড়বে বা পাঠাবে              |
| Python      | Code execute করবে                 |
| File Reader | PDF বা document পড়বে              |
| Browser     | Website-এর সঙ্গে interaction করবে |

Agent-এর কাজ:

1. প্রশ্ন বুঝবে।

3. Search result সংগ্রহ করবে।
4. প্রয়োজনীয় তথ্য বিশ্লেষণ করবে।

### MCP কী?

তুমি আগে MCP-এর নাম শুনেছ। MCP-এর পূর্ণরূপ Model Context Protocol।

এটি AI application-কে external tools ও data sources-এর সঙ্গে একটি standard protocol ব্যবহার করে connect করতে সাহায্য করে।

উদাহরণ:

- MCP Server: Database-এর সঙ্গে যোগাযোগের capability দেয়।
- MCP Client: Agent application থেকে সেই capability ব্যবহার করে।
- MCP Tool: নির্দিষ্ট কাজ সম্পাদন করে।

MCP মানে Agent Framework নয়। এটি মূলত tools ও context connect করার একটি protocol।

Official website: [Model Context Protocol](https://modelcontextprotocol.io/?utm_source=chatgpt.com)

## ৮. কোন technology কখন শিখবে?
