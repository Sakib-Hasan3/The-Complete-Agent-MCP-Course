# Lesson: OpenAI Agents SDK Core Concepts — Agent, Trace and `Runner.run()`

আজকের lesson-এ আমরা OpenAI Agents SDK-এর তিনটি core concept শিখব:

1. Agent — AI-এর role, instructions এবং tools নির্ধারণ করে।
2. `Runner.run()` — Agent-কে asynchronousভাবে চালায় এবং তার কাজের ফলাফল দেয়।
3. Trace — Agent কীভাবে কাজ করেছে, কোন tool ব্যবহার করেছে এবং execution-এর মধ্যে কী ঘটেছে, তা পর্যবেক্ষণ করতে সাহায্য করে।

তুমি যেহেতু Python দিয়ে AI Agent তৈরি শিখছ, আমরা উদাহরণগুলো তোমার IT Helpdesk AI Agent-এর সঙ্গে মিলিয়ে বুঝব।

## 1. পুরো architecture এক নজরে

User Input

"Check ticket 1024"

Agent

Instructions + Model + Tools

Runner.run()

Executes the agent workflow

Trace

Records and helps inspect the execution

Final Answer

"Ticket 1024 is In Progress."

একটি বিষয় মনে রাখবে: Trace হলো execution-এর record ও observability ব্যবস্থা। এটি Runner-এর পরে আলাদা কোনো বাধ্যতামূলক step নয়; execution চলাকালেই trace তৈরি হতে পারে।

## 2. Concept One: `Agent`

`Agent` হলো তোমার AI assistant-এর definition। তুমি এখানে নির্ধারণ করো AI কী কাজ করবে, কীভাবে উত্তর দেবে এবং কোন tools ব্যবহার করতে পারবে।

### Basic code

```
from agents import Agentagent = Agent(    name="IT Helpdesk Agent",    instructions="""    You are an IT helpdesk assistant.    Explain technical problems in simple language.    Never invent ticket information.    """)
```

কোডের প্রতিটি অংশ বুঝি:

- `from agents import Agent` — SDK থেকে `Agent` import করছি।
- `name` — Agent-এর পরিচয়।
- `instructions` — Agent-এর behaviour এবং কাজের নিয়ম।
- `agent` — তৈরি করা Agent object।

এখানে Agent-এর definition তৈরি হয়েছে, কিন্তু এখনো কোনো প্রশ্নের উত্তর তৈরি হয়নি।

### Agent-এর সঙ্গে Tool যুক্ত করা

```
from agents import Agent, function_tool@function_tooldef get_ticket_status(ticket_id: int) -> str:    """Look up the status of a support ticket."""    if ticket_id == 1024:        return "In Progress"    return "Ticket not found"agent = Agent(    name="IT Helpdesk Agent",    instructions="Use the ticket tool to check ticket status.",    tools=[get_ticket_status])
```

এখন Agent-এর কাছে একটি tool আছে। তবে tool ব্যবহার করবে কি না, তা নির্ধারণ করতে model-এর decision এবং SDK-এর execution flow কাজ করে।

Official guide: [Agent definitions documentation](https://openai.github.io/openai-agents-python/agents/?utm_source=chatgpt.com)।

## 3. Concept Two: `Runner.run()`

`Runner.run()` Agent-কে চালায়। এটি asynchronous method, তাই সাধারণত `await` দিয়ে ব্যবহার করতে হয়। এটি একটি `RunResult` return করে।&#x20;

[image](https://www.google.com/s2/favicons?domain=https://openai.github.io\&sz=32)

OpenAI Agents SDK+1



```
from agents import Agent, Runnerimport asyncioagent = Agent(    name="Python Tutor",    instructions="Explain Python concepts for beginners.")async def main():    result = await Runner.run(        agent,        "What is a Python function?"    )    print(result.final_output)asyncio.run(main())
```
[image](https://www.google.com/s2/favicons?domain=https://openai.github.io\&sz=32)

OpenAI Agents SDK+1



### `RunResult` থেকে কী পাওয়া যায়?

```
result = await Runner.run(    agent,    "Explain Python variables.")print(result.final_output)print(result.last_agent.name)
```

- `result.final_output` — Agent-এর final answer।
- `result.last_agent` — Run-এর শেষে যে Agent কাজ শেষ করেছে।

মনে রাখবে: `Runner.run()` একটি run-এর execution পরিচালনা করে। আলাদা user message-এর মধ্যে conversation history ধরে রাখতে চাইলে session বা আগের result-এর input history ব্যবহার করতে হবে।

## 4. Concept Three: Trace

Trace হলো Agent-এর execution-এর বিস্তারিত record। এটি দিয়ে বোঝা যায় Agent কী করেছে, কতগুলো model call হয়েছে, কোন tools ব্যবহার হয়েছে এবং কোথায় error হয়েছে।

ধরো, তোমার Helpdesk Agent ticket status check করতে গিয়ে ভুল উত্তর দিল। শুধু final answer দেখলে হয়তো বোঝা যাবে না সমস্যা কোথায়। Trace দেখে তুমি যাচাই করতে পারবে:

- Agent সঠিক tool নির্বাচন করেছিল কি না।
- Tool-এ সঠিক `ticket_id` পাঠানো হয়েছিল কি না।
- Tool কী result দিয়েছিল।
- Model tool result ভুলভাবে ব্যাখ্যা করেছিল কি না।

SDK-তে tracing সাধারণত default-এ enabled থাকে। Trace-এর ভেতরে একাধিক span থাকে, যা আলাদা execution step উপস্থাপন করে।&#x20;

### Trace এবং Span-এর পার্থক্য

Trace

পুরো workflow বা run-এর execution record।

Span

Trace-এর মধ্যে একটি নির্দিষ্ট operation, যেমন model call, tool call বা handoff।

উদাহরণ:

```
Trace: IT Helpdesk Workflow
│
├── Agent execution
│   ├── Model call
│   ├── Tool call: get_ticket_status
│   └── Model call
│
└── Final answer
```

এটি ধারণাগত উদাহরণ; বাস্তব trace-এর span hierarchy SDK version এবং execution-এর ধরন অনুযায়ী ভিন্ন হতে পারে।

### Trace কীভাবে তৈরি করবে?

```
from agents import Agent, Runner, traceimport asyncioagent = Agent(    name="Python Tutor",    instructions="Explain programming simply.")async def main():    with trace("Python Tutoring Workflow"):        result = await Runner.run(            agent,            "Explain Python lists."        )        print(result.final_output)asyncio.run(main())
```

এখানে `trace()` context manager-এর ভেতরে run-টি execute হচ্ছে। ফলে workflow-টির জন্য একটি named trace তৈরি হয়।

Trace দেখতে ব্যবহার করতে পারো [OpenAI platform logs](https://platform.openai.com/logs?utm_source=chatgpt.com) এবং SDK-এর [Tracing documentation](https://openai.github.io/openai-agents-python/tracing/?utm_source=chatgpt.com)।

Privacy সতর্কতা: Trace-এ input, output বা tool data থাকতে পারে। Sensitive user data থাকলে tracing configuration ও data-redaction policy পরীক্ষা করবে।

## 5. তিনটি Concept একসঙ্গে

| Concept        | নিজেকে যে প্রশ্নটি করবে           |
| -------------- | --------------------------------- |
| `Agent`        | AI-কে কী কাজ করতে বলেছি?          |
| `Runner.run()` | AI-এর কাজটি কীভাবে execute হচ্ছে? |
| `Trace`        | Execution-এর সময় কী ঘটেছিল?       |

সহজ analogy:

- Agent = কর্মীর দায়িত্ব ও নির্দেশনা।
- Runner = কর্মীকে কাজ করানোর ব্যবস্থা।
- Trace = কাজের activity log।
