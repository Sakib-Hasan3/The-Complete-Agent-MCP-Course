# Lesson: OpenAI Agents SDK Intro and Async Python (`asyncio`) Explained

আজকের lesson-এ আমরা দুটি গুরুত্বপূর্ণ বিষয় শিখব:

1. OpenAI Agents SDK: Python দিয়ে কীভাবে একটি AI Agent তৈরি করা যায়, যেটি tools ব্যবহার করতে পারে, একাধিক agent-এর মধ্যে কাজ ভাগ করতে পারে এবং প্রয়োজন অনুযায়ী অন্য agent-এর কাছে কাজ handoff করতে পারে।
2. Async Python (`asyncio`): কীভাবে Python একই সময়ে একাধিক I/O operation পরিচালনা করতে পারে, যাতে AI application অপেক্ষা করতে করতে অযথা সময় নষ্ট না করে।

দুটি বিষয় একে অপরের সঙ্গে সম্পর্কিত। কারণ বাস্তব AI Agent-কে প্রায়ই একাধিক API call, tool execution এবং external service-এর response-এর জন্য অপেক্ষা করতে হয়।

## Part 1: OpenAI Agents SDK কী?

OpenAI Agents SDK হলো Python-এর একটি framework, যার মাধ্যমে agentic AI application তৈরি করা যায়।

এটি দিয়ে তুমি তৈরি করতে পারবে:

- একটি AI assistant বা agent।
- Function/tool calling system।
- একাধিক agent-এর collaboration।
- Agent handoff।
- Input ও output guardrails।
- Execution tracing।

সহজ উদাহরণ:

ধরো, তুমি একটি University Admission Assistant বানাতে চাও।

একজন Student প্রশ্ন করল:

> What are the admission requirements for CSE?

Agent-এর কাজ হবে:

1. প্রশ্নটি বুঝতে পারা।
2. Admission information খুঁজতে tool ব্যবহার করা।
3. প্রয়োজনীয় তথ্য সংগ্রহ করা।
4. Student-কে উত্তর দেওয়া।

একটি AI Agent-এর Basic Architecture

User

Asks a question

Agent

Instructions + Model + Tools

Tool Execution

Search database / Call API / Calculate

Final Response

### 2.1 Agent কী?

একটি Agent তৈরি করতে সাধারণত তিনটি বিষয় লাগে:

- Name
- Instructions
- Model (ঐচ্ছিকভাবে নির্দিষ্ট করা যায়)

উদাহরণ:

```
from agents import Agentagent = Agent(    name="Python Tutor",    instructions="You are a beginner-friendly Python tutor.")
```

এখানে:

- `Agent` হলো SDK-এর class।
- `name` হলো Agent-এর পরিচয়।
- `instructions` হলো Agent-এর system-level behaviour নির্দেশনা।

### 2.2 Runner কী?

Agent তৈরি করলেই সেটি কাজ শুরু করে না। সেটিকে চালাতে হয়।

`Runner` সেই কাজ করে।

```
from agents import Agent, Runneragent = Agent(    name="Assistant",    instructions="You are a helpful assistant.")result = Runner.run_sync(    agent,    "Explain what an AI agent is.")print(result.final_output)
```

এখানে `Runner.run_sync()` হলো synchronous execution-এর পদ্ধতি।

আর `Runner.run()` হলো asynchronous execution-এর পদ্ধতি।&#x20;

## Part 3: একটি বাস্তব Tool তৈরি করা

ধরো, তুমি IT Helpdesk AI Agent তৈরি করছ।

একজন employee জিজ্ঞেস করল:

> What is the status of ticket 1024?

Agent-এর একটি tool থাকবে, যেটি ticket status খুঁজে দেবে।

```
from agents import Agent, Runner, function_tool@function_tooldef get_ticket_status(ticket_id: int) -> str:    """Get the status of an IT support ticket."""    if ticket_id == 1024:        return "Ticket 1024 is currently In Progress."    return "Ticket not found."agent = Agent(    name="IT Helpdesk Agent",    instructions="""    You are an IT helpdesk assistant.    Use the ticket status tool when users ask    about their ticket status.    """,    tools=[get_ticket_status])result = Runner.run_sync(    agent,    "What is the status of ticket 1024?")print(result.final_output)
```

এখানে কী ঘটছে?

1. `@function_tool` Python function-টিকে Agent-এর tool হিসেবে expose করছে।
2. `ticket_id: int` থেকে argument-এর type জানা যাচ্ছে।
3. Docstring থেকে tool-এর উদ্দেশ্য বোঝা যাচ্ছে।
4. `tools=[get_ticket_status]` দিয়ে Agent-কে tool দেওয়া হচ্ছে।
5. Agent প্রয়োজন মনে করলে tool call করছে।
6. Tool-এর result ব্যবহার করে final answer তৈরি করছে।

এখানে ticket-এর তথ্য hardcoded demo data। বাস্তব project-এ function-এর মধ্যে database query বা API call থাকবে।

## Part 5: Async Python (`asyncio`) কী?

এখন lesson-এর দ্বিতীয় অংশ।

প্রথমে একটি বাস্তব উদাহরণ চিন্তা করো।

তুমি তিনটি API call করবে:

- Groq API
- Qdrant API
- Weather API

প্রতিটি API response দিতে ২ সেকেন্ড সময় নিচ্ছে।

Synchronous approach: একটি শেষ হওয়ার পর পরেরটি শুরু হবে।

Asynchronous approach: একটি API response-এর জন্য অপেক্ষা করার সময় অন্য API call-ও চলতে পারবে।

এ কারণে I/O-bound কাজের ক্ষেত্রে async programming অনেক সময় বাঁচাতে পারে।

### 5.1 Synchronous Programming

```
import timedef task1():    print("Task 1 started")    time.sleep(2)    print("Task 1 finished")def task2():    print("Task 2 started")    time.sleep(2)    print("Task 2 finished")task1()task2()
```

সম্ভাব্য output:

```
Task 1 started
Task 1 finished
Task 2 started
Task 2 finished
```

Total time ≈ 4 seconds

কারণ Task 2 শুরু হওয়ার আগে Task 1 শেষ হয়েছে।

### 5.2 Asynchronous Programming

এবার একই কাজ `asyncio` দিয়ে করি।

```
import asyncioasync def task1():    print("Task 1 started")    await asyncio.sleep(2)    print("Task 1 finished")async def task2():    print("Task 2 started")    await asyncio.sleep(2)    print("Task 2 finished")async def main():    await asyncio.gather(        task1(),        task2()    )asyncio.run(main())
```

সম্ভাব্য output:

```
Task 1 started
Task 2 started
Task 1 finished
Task 2 finished
```

Total time ≈ 2 seconds

কারণ Task 1 অপেক্ষা করার সময় Task 2-ও চলেছে।

এখানে `asyncio.sleep()` ব্যবহার করেছি, কারণ এটি অপেক্ষা করার সময় event loop-কে অন্য task চালানোর সুযোগ দেয়।

Python documentation-এ `asyncio.gather()` দিয়ে একাধিক awaitable concurrent execution-এর উদাহরণ রয়েছে।&#x20;

## Part 6: Async Python-এর গুরুত্বপূর্ণ Keywords

এগুলো ভালোভাবে বুঝতে হবে।

### 6.1 `async`

কোনো function asynchronous coroutine হিসেবে define করতে `async def` ব্যবহার করা হয়।

```
async def say_hello():    print("Hello!")
```

এটি সাধারণ function-এর মতো সরাসরি execute হয় না। এটি একটি coroutine object তৈরি করে।

### 6.2 `await`

কোনো asynchronous operation-এর result-এর জন্য অপেক্ষা করতে `await` ব্যবহার করা হয়।

```
import asyncioasync def get_data():    await asyncio.sleep(2)    return "Data received"async def main():    result = await get_data()    print(result)asyncio.run(main())
```

Output:

```
Data received
```

### 6.3 `asyncio.run()`

একটি Python program-এর top-level asynchronous function চালানোর জন্য ব্যবহার হয়।

```
asyncio.run(main())
```

এটি event loop তৈরি করে, coroutine চালায় এবং শেষে loop বন্ধ করে।

### 6.4 `asyncio.gather()`

একাধিক asynchronous operation একসঙ্গে schedule করে এবং সেগুলো শেষ হওয়া পর্যন্ত অপেক্ষা করে।

```
results = await asyncio.gather(    get_data(),    get_data(),    get_data())
```

সব result একটি list হিসেবে পাওয়া যাবে। Result-এর order input-এর order অনুযায়ী থাকবে।&#x20;

### 6.5 Event Loop কী?

Event Loop হলো asynchronous Python-এর scheduler।

এটি বিভিন্ন task-এর মধ্যে execution পরিচালনা করে।

ধরো:

- Task A একটি API response-এর জন্য অপেক্ষা করছে।
- Task B একটি database query করছে।
- Task C আরেকটি API response-এর জন্য অপেক্ষা করছে।

Task A যখন অপেক্ষা করছে, Event Loop Task B বা C-কে execution-এর সুযোগ দিতে পারে।

Event Loop-এর সহজ ধারণা

Event Loop

Schedules and coordinates tasks

Task A

Waiting

API response

Task B

Running

Database

Task C

Waiting

API response

একটি task অপেক্ষা করলে অন্য ready task চলতে পারে।

একটি গুরুত্বপূর্ণ পার্থক্য:

- Concurrency: একাধিক task-এর অগ্রগতি overlapping সময়ে পরিচালনা করা।
- Parallelism: একাধিক task সত্যিকার অর্থে একই সময়ে একাধিক CPU core-এ execute হওয়া।

`asyncio` সাধারণত single-threaded event loop-এ concurrency পরিচালনা করে। এটি নিজে থেকে CPU-heavy কাজকে parallel করে না।&#x20;

## Part 7: OpenAI Agents SDK + Asyncio একসঙ্গে

এখন আগের দুটি বিষয় একসঙ্গে ব্যবহার করি।

ধরো, তোমার তিনটি আলাদা user question আছে। তুমি প্রতিটির জন্য Agent চালাতে চাও।

প্রথমে একটি Agent তৈরি করো:

```
from agents import Agent, Runnerimport asyncioagent = Agent(    name="Python Tutor",    instructions="Explain Python in simple language.")
```

এরপর async function:

```
async def ask_agent(question):    result = await Runner.run(        agent,        question    )    return result.final_output
```

এখন একাধিক প্রশ্ন একসঙ্গে পাঠাও:

```
async def main():    questions = [        "What is a Python variable?",        "What is a Python function?",        "What is a Python loop?"    ]    results = await asyncio.gather(        *(ask_agent(q) for q in questions)    )    for answer in results:        print(answer)        print("----------------")asyncio.run(main())
```

এখানে কী ঘটছে?

1. `agent` একটি Python Tutor Agent।
2. `ask_agent()` একটি asynchronous function।
3. `Runner.run()` Agent-কে async পদ্ধতিতে চালায়।
4. `asyncio.gather()` তিনটি প্রশ্নের কাজ concurrent করে।
5. সব result পাওয়া গেলে সেগুলো print হয়।

এটি একই Agent-এর তিনটি আলাদা run। প্রতিটি run-এ conversation context আলাদাভাবে না দিলে আগের প্রশ্নের উত্তর পরের প্রশ্নে স্বয়ংক্রিয়ভাবে যুক্ত হবে না।

## Part 8: `asyncio.gather()` বনাম Sequential Await

এই দুটি code-এর পার্থক্য বোঝা জরুরি।

Sequential:

```
result1 = await ask_agent("Explain Python.")result2 = await ask_agent("Explain Java.")result3 = await ask_agent("Explain C++.")
```

এখানে প্রথম call শেষ হলে দ্বিতীয় call শুরু হবে।

Concurrent:

```
result1, result2, result3 = await asyncio.gather(    ask_agent("Explain Python."),    ask_agent("Explain Java."),    ask_agent("Explain C++."))
```

এখানে তিনটি call concurrent চলতে পারে।

তবে API rate limit, network failure এবং provider-এর concurrency limit বিবেচনা করতে হবে। অনেকগুলো request একসঙ্গে পাঠানোর আগে concurrency limit নির্ধারণ করা ভালো।

## Part 9: Asyncio-এর কিছু গুরুত্বপূর্ণ সতর্কতা

| ভুল                                            | সঠিক পদ্ধতি                                  |
| ---------------------------------------------- | -------------------------------------------- |
| `async def` call করে await না করা              | `await function()`                           |
| Async function-এর মধ্যে `time.sleep()` ব্যবহার | `await asyncio.sleep()`                      |
| একসঙ্গে অনেক API call পাঠানো                   | Concurrency limit ব্যবহার                    |
| CPU-heavy code সরাসরি event loop-এ চালানো      | প্রয়োজন হলে process/thread ব্যবহার           |
| Nested `asyncio.run()` চালানো                  | Existing event loop-এর মধ্যে `await` ব্যবহার |

বিশেষ করে: Jupyter Notebook বা Kaggle Notebook-এ অনেক সময় event loop আগে থেকেই চালু থাকে। সেখানে সাধারণত `asyncio.run(main())`-এর পরিবর্তে সরাসরি `await main()` ব্যবহার করতে হয়।

আর `asyncio.gather()`-এর default behaviour-এ একটি task exception দিলে সেই exception caller-এর কাছে propagate হয়; অন্য submitted task-গুলো স্বয়ংক্রিয়ভাবে cancel হয় না। Production code-এ error handling দরকার।&#x20;
