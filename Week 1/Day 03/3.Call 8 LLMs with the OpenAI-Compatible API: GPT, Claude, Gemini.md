এই lesson-এ আমরা শিখব কীভাবে একটি OpenAI-compatible API format ব্যবহার করে একাধিক LLM-এর সঙ্গে যোগাযোগ করা যায় এবং একই প্রশ্ন ৮টি model-কে পাঠিয়ে তাদের উত্তর তুলনা করা যায়।

এটি Agentic AI শেখার জন্য গুরুত্বপূর্ণ, কারণ বাস্তব AI application-এ অনেক সময় একটি model-এর ওপর নির্ভর না করে একাধিক model পরীক্ষা করা হয়।

## ১. OpenAI-Compatible API কী?

ধরো, তুমি OpenAI API ব্যবহার করে একটি request পাঠাচ্ছ:

- API endpoint
- API key
- Model name
- Prompt / message

সাধারণ OpenAI-compatible API-তেও প্রায় একই request structure ব্যবহার করা যায়।

অর্থাৎ, কোনো provider যদি OpenAI-compatible API support করে, তাহলে তার API-তে request পাঠানোর জন্য OpenAI SDK বা একই ধরনের HTTP request ব্যবহার করা সম্ভব হতে পারে।

একটি common request structure

REQUEST

`API URL + API KEY + MODEL + PROMPT`

GPT

Claude

Gemini

একই ধরনের request format, কিন্তু provider অনুযায়ী URL, key ও model আলাদা।

মনে রাখবে: OpenAI-compatible মানে এই নয় যে সব provider-এর API একদম একই। Endpoint, authentication, model name, supported features এবং response format আলাদা হতে পারে।

## ৩. Python দিয়ে ৮টি model call করার পদ্ধতি

এখানে আমরা Python-এর `openai` package ব্যবহার করব। একই SDK দিয়ে provider অনুযায়ী `base_url`, API key ও model name পরিবর্তন করব।

### Step 1: Package install

তোমার terminal-এ চালাও:

```
pip install openai python-dotenv
```

- `openai`: OpenAI-compatible API request পাঠাবে।
- `python-dotenv`: `.env` file থেকে API key পড়বে।

### Step 2: API keys সংরক্ষণ

Project folder-এ `.env` নামে file তৈরি করো।

```
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
GEMINI_API_KEY=your_gemini_key
```

নিজের আসল API key বসাবে। GitHub-এ `.env` upload করবে না।

### Step 3: আটটি model-এর configuration

নিচের তালিকাটি একটি উদাহরণ। Model ID provider-এর বর্তমান model list থেকে যাচাই করে প্রয়োজনমতো পরিবর্তন করবে।

| No. | Provider | Model ID                |
| --- | -------- | ----------------------- |
| 1   | OpenAI   | `gpt-6`                 |
| 2   | OpenAI   | `gpt-6-mini`            |
| 3   | OpenAI   | `gpt-6-nano`            |
| 4   | Claude   | `claude-opus-5-5`       |
| 5   | Claude   | `claude-sonnet-5-5`     |
| 6   | Gemini   | `gemini-3.8-flash`      |
| 7   | Gemini   | `gemini-3.1-flash-lite` |

Model ID-গুলো শেখানোর উদাহরণ; এগুলো তোমার account-এ enabled বা বর্তমানে available থাকবে—এমন নিশ্চয়তা নেই।

### Step 4: Python code

এবার `main.py` তৈরি করে নিচের code বসাও।

প্রথমে configuration-এ নিজের account-এ available model ID বসাতে হবে। এতে ভুল বা unavailable model-এর কারণে পুরো program বন্ধ হবে না।

```
    config = PROVIDERS[provider]    if not config["api_key"]:        return name, "ERROR: API key missing"    try:        client = OpenAI(            api_key=config["api_key"],            base_url=config["base_url"],        )        response = client.chat.completions.create(            model=model_id,            messages=[                {                    "role": "system",                    "content": "You are a helpful AI tutor."                },                {                    "role": "user",                    "content": QUESTION                }            ],        )        answer = response.choices[0].message.content        return name, answer    except Exception as error:        return name, f"ERROR: {error}"# একসঙ্গে ৮টি model-এ request পাঠানোwith ThreadPoolExecutor(max_workers=8) as executor:    futures = [        executor.submit(ask_model, name, provider, model_id)        for name, provider, model_id in MODELS    ]    for future in as_completed(futures):        name, answer = future.result()        print("\n" + "=" * 60)        print(name)        print("=" * 60)        print(answer)
```

Run করবে:

```
python main.py
```

এই code-এ কী হচ্ছে?

1. `.env` থেকে তিনটি provider-এর API key পড়ছে।
2. প্রত্যেক provider-এর জন্য আলাদা `base_url` নির্ধারণ করছে।
3. আটটি model-এর জন্য একই প্রশ্ন পাঠাচ্ছে।
4. `ThreadPoolExecutor` request-গুলো parallel-এ চালাচ্ছে।
5. প্রতিটি model-এর উত্তর আলাদাভাবে print করছে।
6. কোনো model error দিলে অন্য model-এর result পাওয়ার চেষ্টা চালিয়ে যাচ্ছে।

## ৫. আটটি model call করলে কী সুবিধা?

ধরো, তুমি একই প্রশ্ন আটটি model-কে দিলে। তখন তুমি তুলনা করতে পারবে:

| Evaluation metric | কী যাচাই করবে?                     |
| ----------------- | ---------------------------------- |
| Response quality  | কোন উত্তর সবচেয়ে ভালো?             |
| Accuracy          | তথ্য সঠিক কি না?                   |
| Latency           | কত সময়ে উত্তর দিয়েছে?              |
| Cost              | কত খরচ হয়েছে?                      |
| Consistency       | একই প্রশ্নে উত্তর কতটা consistent? |

সতর্কতা: আটটি model-এ একই সঙ্গে request পাঠালে API usage ও খরচও বাড়বে। Rate limit, timeout এবং provider-এর compatibility limitation থাকতে পারে।
