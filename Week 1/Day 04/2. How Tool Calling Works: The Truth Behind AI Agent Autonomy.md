## ১. Tool Calling কী?

Tool Calling বা Function Calling হলো এমন একটি mechanism, যার মাধ্যমে LLM তোমার application-কে কোনো নির্দিষ্ট function বা external tool চালানোর অনুরোধ করতে পারে।

ধরো, তুমি AI Agent-কে বললে:

"ঢাকার আজকের আবহাওয়া কেমন?"

LLM-এর training data থেকে আজকের live weather জানা সম্ভব নয়। তাই তাকে Weather API ব্যবহার করতে হবে।

এখানে:

- LLM: বুঝবে আবহাওয়ার তথ্য প্রয়োজন।
- Tool: Weather API call করবে।
- Application: API execute করবে।
- LLM: পাওয়া তথ্য দিয়ে উত্তর তৈরি করবে।
